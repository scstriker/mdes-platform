## 采用的输入和口径

原始材料位于本次工作区根目录的 `docs/`，平台仓库位于其同级的 `mdes-platform/`。交接稿和迁移包用于了解老系统。本期字典以用户给出的正式 CSV 为准。

| 材料 | 在本期的用途 |
| --- | --- |
| 医疗器械HS编码最终版_202601_164项.csv | 版本 `202601`，164 个 HS8、117 个 HS6、11 个一级类别。文件 SHA-256 为 `ab8e97496fbc9500877f02adc61ab214788f79234b9cb1f565a98f77a683a59b`。 |
| 我国海关平台-2024年度仪器仪表海关进出口年度数据统计.xlsx | 海关年度验收基准。明细为美元，汇总表为万美元。可对账 37 个重合税号的进口和其中 36 项已知出口值。 |
| 联合国数据-【0407】2023年仪器仪表国际贸易进出口数据（合稿）.xlsx | 参照国际贸易字段。报告国对世界金额与中国海关对单个伙伴的金额分别定义。 |
| 数据采集、清洗及分析-数据查询操作说明.pdf、china_customs_suite.user.js | 用于定义官网查询分组、原件、双数量及计量单位。本期以单月和单流向确定来源期间。 |

首个可复核的数值来自金标准 `Sheet1` 第 105 行。税号 `90181100` 在 2024 年进口 20,375,226 美元、出口 89,723,246 美元，顺差 69,348,020 美元。这三个数是独立验收期望值。开发时须从实际月度原件生成结果。
