# 中国海关贸易后端功能设计

本规格供实现 38 号导入向导、Hono 路由和 D1 迁移的开发者使用。业务输入是海关月度统计，输出是可追溯到原件的已发布期间。下文描述待开发行为。需求编号见 [PRD](PRD.md)，请求和响应见 [API](API.md)。

## 一笔导入怎样生效

以 `202601 / 2024-01 / import / USD / partner / [90181100]` 为例，这是一次针对心电图记录仪进口伙伴结构的查询。相同条件下可能有多个伙伴行。商品全国总额由另一次 `product` 查询提供。即使两个文件金额合计相等，也分别保存。

| 环节 | 后端行为 | 管理员能看到什么 |
| --- | --- | --- |
| 收件 | 读取清单和上传字节，计算 SHA-256；根据清单确定字典、月份、流向、分组与税号集合。 | 文件、请求范围、来源摘要，或需要更正的字段。 |
| 解析 | 按实际表头识别 HS8、可选的分组代码与名称、两组数量和单位、美元金额。以数字文本保留代码，金额按源精度解析。逐行核对税号归属及业务键。 | 数据行数、已取得/明确无记录/待补采的税号；错误注明原文件行号与字段名。 |
| 暂存 | 经校验的事实按批次分块写入候选版本。相同范围、相同原件和相同覆盖声明的重放复用原批次。 | `staged` 表示已收件；待补采部分可以从当次回执定位。 |
| 发布 | 按当年适用税号核齐两种流向的四个分组，复核全国金额与分组按 HS8 的汇总。候选事实和快照准备完成后，一次切换版本及对应观测值。 | `published`、统计期、发布版本和来源批次。迟到的批次补齐后重新评估该月。 |

文件级或行级错误使整份贸易文件退回更正；原文件重传后可重试。缺采是一项覆盖结果：格式正确的已收文件可暂存，上一版正式结果仍可查。出现相同业务键的两行时，管理员得到行号以复核来源，后端不将这两行重复计额。

## D1 写入与修订

| 数据 | 写入约束或读取索引 |
| --- | --- |
| 版本字典与历年适用情况 | 用 `(dictVersion, hs8)` 定位类别和 HS6。某码在历史年份不适用时记录年份与目录依据，年度覆盖单列这一项。 |
| 导入及覆盖 | 在已有 `import_batch` 外关联贸易清单、来源摘要和每码覆盖。范围键包括版本、年月、流向、币种、分组、排序去重后的请求 HS8 集合；批次标识另包含来源和覆盖证据。 |
| 月度事实 | 同一批次内以 `(batchId, hs8, groupCode)` 唯一；`product` 的 `groupCode` 固定为 `ALL`。其他三组使用各自的海关原码。按批次读取候选行，按范围定位上一批。 |
| 发布快照与派生观测 | 快照记录字典、期间、版本、来源批次和门户响应。读取当前版本使用 `(dictVersion, period)` 唯一索引；观测值保留来源和同一期间的发布版本。 |

一次修订替换**同一请求范围的整份数据**。例如原文件包含伙伴 A、B，修订版只剩 A，则新版中 B 随原批移出。重新提交曾经的旧文件只返回历史批次，不把旧版重新发布。如果只获得部分重叠税号的修订文件，回执返回冲突范围，采集端按原覆盖集合重新导出。

一个月多个分组须同步修订时，先暂存，待分组重新对账后一起发布。重算该月、所属季度、全年以及包含该月的年内累计，还要重算以这组月份作为同比基期的已发布期间。耗时聚合在切换前完成；最终 D1 事务只激活已准备好的版本及其派生结果。并行修订以当前版本为前提提交；版本已变时重新计算。中断后可依据原件和候选批次继续。

## 指标怎样生成

| 输出 | 取数和算法 | 对应入口 |
| --- | --- | --- |
| 进口、出口、差额 | 同一期间从 `product` 按流向合计，差额为出口减进口；先在美元上求和，再进行显示换算。11 类按 HS8 对应大类汇总。 | `TRD-001/002`、专题 KPI、品类表 |
| 伙伴结构 | 在 `partner` 中按海关伙伴原码、同一流向求和；进口对应原产国或地区，出口对应目的国或地区。份额取伙伴额除以同范围全国额。排除世界及合计行，保留海关实际列出的未列名地区代码。 | `TRD-005`、伙伴表 |
| 进口与出口集中度 | 以已对账伙伴数据计算。先按伙伴合并所选期间内的金额，再算全部份额。降序取前 1、3、5 名的份额之和；HHI 为全部百分数份额的平方和。伙伴数少于 k 时取已有伙伴，分母为零时返回空值。 | `TRD-006/007`、品类与 HS8 排名 |
| 注册地、贸易方式与同比 | 两种结构分别从 `region`、`regime` 汇总。同比为（本期金额减同期金额）除以上年同期金额；使用覆盖相同的月份和可比税号，缺基期或基期为零返回空值。 | 注册地和方式表、趋势、指标详情 |

金额的全国值与分组值逐码对账，记录源文件精度和差额。存在未解释的差额时保持待复核。对账结果保留原数；源端修订或取整差异必须能由同期间原件说明。金额比例在计算结束后统一舍入。第一数量和第二数量分别按税号及相同单位统计。

## 页面与测试入口

38 号向导识别海关原件后使用贸易导入契约，普通指标 CSV 继续使用已有导入入口。专题、详情和导出使用相同 `period`、`dictVersion` 和 `releaseId`。搜索从同版品类、税号、伙伴得到命中项；后台观测值定位到同版 TRD 派生记录。查询端返回已发布快照，空库和未发布期间按 API 契约显示。

第一轮用隔离的单码字典范围验证真实原件、导入与年度结果；随后在本地 Miniflare 验证重放、撤回、混合分组和发布中断。扩充历史事实后，比较同一快照查询的索引计划、读取行数及 P95。每个行为所需的输入、期望值和留证项见[业务验收用例](贸易业务验收用例.md)。
