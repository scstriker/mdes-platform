在包含本套文档的 `mdes-platform` 工作目录打开新的开发会话，复制下面整段。业务事实、接口和验收值以同目录规格为准。

```text
开始开发中国海关医疗器械进出口后端。按 git → plan → goal + TDD 执行。目标是将海关月度原始 CSV 变为可追溯的门户数据，让 38 号导入向导、贸易专题、指标详情、搜索及图表导出使用同一发布版本。

先读仓库约定和 docs/贸易后端开发记录.md。采集以 docs/海关原件采集规程.md 为准，后端行为以 docs/贸易后端功能设计.md 为准，测试和人工对账使用 docs/贸易业务验收用例.md。PRD、TECH_SPEC、DATA_MODEL、API、ACCEPTANCE 和 ADR-004 给出共享契约。沿用本仓库 Hono、D1、React Query、ECharts 和既有测试环境。

一、Git 与 Plan
检查分支、未提交修改和已有历史。在包含本套规格的提交上另建功能分支，合入 ui/itei-refactor@49b8274 已交付的 UI。保留现有工作。把计划和验证入口写进开发记录，再开始 G1。

二、创建可验证的 Goal
以 AC-013 至 AC-017 为完成条件。每次只推进一个可通过导入接口、查询接口或页面观察的行为。每轮先写失败验证，记录实际失败，再写最小实现，验证通过后重构。

G1 / AC-013　贯通单个真实税号。取 90181100 心电图记录仪的 2024 年海关月度美元原件与查询清单。在隔离的单码库，经正常导入与读取入口还原年度进口 20,375,226 美元、出口 89,723,246 美元、顺差 69,348,020 美元。固定期望值来自 2024 海关金标准 Sheet1 第 105 行。所需原件尚待采集时，记录缺少的月份和流向。解析、币种和事务可先用标明用途的小夹具测试，保留真实原件验收待办。

G2 / AC-014　用本地 Miniflare 顺序应用所有迁移。验证重放、修订撤回一行、发布中断和重试。发布状态和查询结果通过接口断言。

采集与导入共用同一个清单格式。先完成单码、单月的八个查询组合，再按固定编码组扩大。业务验收用例中的原始美元、修订前后 A/F 两行、历史重放结果和累计 HHI 都是独立的测试依据。将官网明确无记录的证据与待补采状态分开登记。

G3 / AC-015　按验收文档的六伙伴样例验证进出口两侧的月度与跨月 CR、HHI 和同比，核对金额单位、统计期间及分组。

G4 / AC-016　38 号向导提交原件和清单。接通专题、详情、搜索、后台观测值和图表导出。用 Playwright 跑一遍数据流。记录快照索引计划、读取行数，以及相同环境中预热后多次请求的 P95。

G5 / AC-017　扩至 202601 字典的 164 个 HS8，按 11 类统计。默认回填 2024 年 1 月至最新公布的完整月份。按税号、月份、流向和分组登记覆盖；用样表中有对照值的税号逐项复核。完成月份按约定发布，保留来源摘要和批次。

三、提交与交付
按“单码贯通、批次与统计、门户接入、全量数据验收”分批本地提交，每批记下命令、证据、覆盖范围、遗留事项和提交号。用项目的测试、构建和关联的端到端测试验收对应变更。最终交付更新后的开发记录，写明哪些 Goal 已有验证证据。
```
