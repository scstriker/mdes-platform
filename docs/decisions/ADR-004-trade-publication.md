# ADR-004　按月保存海关事实，按统计期发布快照

**状态**　拟实施，2026-11-22。沿用 [ADR-003 的 D1 选型](ADR-003-cloudflare-d1.md)。

## 背景

用户会多次打开同一专题页，海关数据按月更新，也会事后修订。专题、指标详情、搜索和导出需要引用同一版本。若每次打开页面都重扫事实表，同一组统计需反复计算。若只保留年度合计，一次月度修订又难以回溯。

## 决定

按月、流向、HS8 和查询分组保存来源事实。商品全国合计负责规模指标，伙伴明细负责集中度，贸易方式和注册地各自成表展示。导入端完成聚合后发布版本快照；请求端按期间和版本索引读取。记录每次发布引用的批次和海关原件哈希。

## 影响

页面读取成本由返回的快照大小决定。历史月份修订会增加一次重算，范围包括该月所属季度、年度、累计期间和受影响的同比。月度事实和原件可用来重新生成快照。单码开发样本进入隔离测试库，门户正式发布按清单覆盖情况判断。

验收依据见 [AC-014 至 AC-017](../ACCEPTANCE.md)，模型和索引见[数据模型](../DATA_MODEL.md)。
