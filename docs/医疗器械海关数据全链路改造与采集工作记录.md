## 一、第一性原理架构诊断与 GitHub 同类方案比选结论

### 1.1 核心痛点与第一性原理决策
1. **采集端“以单次信息密度替代请求并发”**：
   - 旧版 `docs/china_customs_suite.user.js`（v3.4.0）仍为 173 项仪器仪表目录、默认人民币、逐码请求且仅 `100ms` 间隔（`10 QPS` 高频风险），`port_detail` 分支未实现；而单自然月死板切分抓取 5 年（58 个月）需 4,176 次导出与上万次浏览器下载弹窗。
   - **重构决定**：升级 `china_customs_suite.user.js` 至 `v4.0.0`（锁定 `202601` 正式字典 164 个医疗器械 HS8、11 个一级类别、USD 美元），启用海关原生 `monthFlag="1"`（单自然年 `01–12` 月输出 `数据年月 YYYYMM` 列）+ `/queryData/getQueryDataListByWhere` 行数预检（`< 9,000` 行直拉全年，超限自动二分时间窗），配合 **`SerialFlightLock` 全局单飞互斥锁（`MAX_INFLIGHT = 1`）**、**`3.5s–6.5s` 随机抖动间隔**、**组间 `15s–25s` / 跨年 `45s–60s` 多级冷却**与 **HTML/412 即时熔断断点续采**，通过 `browser-harness` 单持久 CDP 连接将原字节经本地 32 MiB IPC 直写磁盘。
2. **入库端“延迟批量单次向量化发布”**：
   - 保持现有单批 `POST /api/trade/import` 100% 向后兼容，新增支持 `monthFlag="1"` 多月原件按月无损拆分的 `POST /api/trade/import-bulk`（支持 `deferPublish=true`）与显式单次原子发布接口 `POST /api/trade/publish`，消除历史 5 年回填时的 `O(M²)` 重复重算；门户读取维持 `trade_current_snapshot` 主键单行命中（`rows_read = 1`）。
3. **分析与可视化全面对齐样表与标杆项目**：
   - 对齐《我国海关平台-2024年度仪器仪表海关进出口年度数据统计.xlsx》（`Sheet1` 16 列美元/数量及同比、`汇总表` 亿美元/万美元双表）、《数据采集、清洗及分析-数据查询操作说明.pdf》与 `scstriker/customs-data`，补齐 **进出口总额 KPI**、**2022–2026 跨年年度走势图**、**11 大类产品构成环形饼图**、**伙伴 Top 10 / 国内省市 Top 10 / 贸易方式横向条形图**、**HS8 第一数量同比**、**确定性研判文段（严格区分相邻年“同比”与跨多年“区间变化”）** 及 **一键导出 A4 报告与年度统计汇总 CSV**。

### 1.2 GitHub 同类实现比选摘要
- **采集与浏览器控制层**：对比 `browser-use/browser-harness`（19.2k★，持久 CDP 守护进程 + 32 MiB IPC + 原生 Python 编排）、`wuhulamb/customs-data`（控制台手工脚本 + Python 校验）、`2218084076/get_customs_data`（Playwright DOM 200 行/页翻页，慢 50 倍）、`pinchtab/pinchtab` / `browserbase/stagehand` / `vercel-labs/agent-browser`（AI 逐步视觉/AX 代理）及瑞数 6 逆向补环境方案，选定 **`browser-harness` + `china_customs_suite.user.js` v4.0 单飞低频串行桥接**，并参考 `turbanisch/chinautils` 历年海关 HS8 字典核验 2022–2026 税号适用性。
- **存储与可视化层**：实测 5 年 164 码四分组月度事实总量 `< 100 万行`（`~1%` D1 容量上限）。对比 `tesseract-olap/tesseract`（ClickHouse）、`cid-harvard/atlas-economic-complexity` / `ropensci/tradestatistics`（PostgreSQL 分层汇总）、`tradewartracker`（DuckDB/Parquet）与 `scstriker/customs-data`（Electron 内存态），选定 **保持 Cloudflare Workers + D1（月度事实 + 写时物化多期快照）+ ECharts 6 SVG**，零架构撕裂且读取恒定 `O(1)`。
