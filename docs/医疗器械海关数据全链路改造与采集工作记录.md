## 一、第一性原理架构诊断与自主拍板决策清单

### 1.1 四大工程瓶颈与第一性原理破局
1. **采集端“以单次信息密度替代请求并发”**：
   - 旧版 `docs/china_customs_suite.user.js`（v3.4.0）内置 173 项仪器仪表目录、默认人民币（`rmb`）、按单税号循环且仅设 `100ms` 延迟（约 `10 QPS`，极易触发海关瑞数 6 动态 WAF `412` 封禁），`port_detail` 分支未落地；若沿用单月单流向切分抓取近 5 年（58 个完整月），需发起 `4,176` 次下载并触发数千次浏览器保存弹窗。
   - **第一性原理方案**：升级 `china_customs_suite.user.js` 与 `scripts/china_customs_collector.user.js` 至 `v4.0.0`，锁定正式字典 `202601`（164 个医疗器械 HS8、117 个 HS6、11 个一级类别，SHA-256 `ab8e97496fbc9500877f02adc61ab214788f79234b9cb1f565a98f77a683a59b`）与 `USD` 美元，启用海关原生 **`monthFlag="1"` 年度按月分列输出**（单自然年 `1..12` 月一次返回带 `数据年月 YYYYMM` 列的月度明细）+ `/queryData/getQueryDataListByWhere` 行数预检（`< 9,000` 行直拉全年，`>= 9,000` 行自动二分月份窗口），配合 **`SerialFlightLock` 全局单飞互斥锁（`MAX_INFLIGHT = 1`）**、**`3.5s–6.5s` 随机抖动间隔（硬下限 `>= 2.5s`）**、**每 8 次请求 `15s–25s` 组间休息 + 跨年 `45s–60s` 冷却**，通过 `browser-use/browser-harness` 单持久 CDP 通道将原始字节 Base64 直传落盘。
2. **入库端“延迟批量暂存 + 单次向量化发布”**：
   - 保留单月 `POST /api/trade/import` 100% 向后兼容；新增支持 `monthFlag="1"` 多月 CSV 按自然月无损拆解的 `POST /api/trade/import-bulk`（支持 `deferPublish=true`）与显式单次原子发布接口 `POST /api/trade/publish`。
   - 对账阶段采用 SQLite 原生 `GROUP BY month, flow, grouping, hs8` 汇总比对，事实读取采用 `24` 批次分片 + `25,000` 行游标分页与循环追加（彻底消除 V8 `push(...results)` 调用栈溢出与远程 D1 单次 RPC 体积上限），快照写入按 `10` 个期间分批落盘，使近 40 万行 5 年全量明细在数秒内完成单版本（`1` 条 `trade_release`）发布，而门户读取维持 `trade_current_snapshot` 唯一主键单行命中（`rows_read = 1`）。
3. **口径与历年税则严密对齐**：
   - 针对用户未显式展开的隐含工程问题，经核查海关真站时间锚点与 2022–2026 历年《中华人民共和国进出口税则》自主拍板定案：
     - **采集时间窗**：锁定 **`2022-01` 至 `2026-10`（共 58 个完整自然月）**，起点与 WCO 第七版《协调制度》（`HS 2022`，2022-01-01 生效）严格对齐，规避 2021 年（`HS 2017`）大规模医疗器械子目拆并导致的伪同比断层；终点对齐真站 `#currentEndTime = "202610"`。
     - **历年税号适用性**：核实 164 个 HS8 在 `2023–2026` 年全量有效；唯独 **`90189080`（手术机器人）** 系 2023 年关税调整自 `90189099` 析出增列，故通过 `0007_trade_hs_2022_2026_applicability.sql` 将 `2022` 年 `90189080` 精确标记为 `applicable = 0`（`2022` 年适用 `163` 码，`2023–2026` 年适用 `164` 码）。
     - **币制与展示量纲**：采集锁死 `currencyType="usd"`，入库存储 `usd_scaled = USD × 10,000` 定点整数，门户主展示单位 `亿美元` 并附精确原始美元整数与双表汇总（`亿美元` + `万美元`）。
     - **双数量同比口径**：仅在当年与上年同税号第一计量单位一致且非空时计算 `importQty1YoyPct` / `exportQty1YoyPct`，异构单位返回 `null`。
4. **可视化与报告导出全面对齐参考资料**：
   - 对齐《我国海关平台-2024年度仪器仪表海关进出口年度数据统计.xlsx》（`汇总表` + `Sheet1` 16 列）、《数据采集、清洗及分析-数据查询操作说明.pdf》与 `scstriker/customs-data`，将 `/trade` 升级为 **5 栏核心 KPI** + **确定性态势研判摘要框** + **2×2 四维旗舰图表矩阵** + **一键导出自包含 A4 分析报告 HTML 与双表年度统计汇总 CSV**。

## 四、分轮次 TDD 红绿实录与真站联调关键发现

### 4.1 G6 / AC-018：油猴 v4.0 与低频单飞串行桥接
- **Red 真实报错**：
  - `customs-suite-v4.test.ts` 首轮执行失败：`ReferenceError: window is not defined (china_customs_suite.user.js:18:3)`（旧 v3.4.0 无非 DOM 沙箱保护、无 `__CUSTOMS_SUITE_BRIDGE__`、仍为 173 项仪器仪表）；
  - `unittest` 首轮失败：`ModuleNotFoundError: No module named 'collect_customs_5y'`。
- **Green 实现与真站 Chrome + `browser-harness` 联调五项关键加固**：
  1. **HTTP 80 端口专有服务与禁止 HTTPS 自动升级**：实测 `http://stats.customs.gov.cn/` 仅开放 HTTP 80 端口（无 443 端口），新 Chrome Profile 默认 `HttpsUpgrades` 会导致跳转 `https://` 报错；在 `ensure_dedicated_chrome_cdp` 增加 `--disable-features=HttpsFirstBalancedModeAutoEnable,HttpsUpgrades` 后直连成功。
  2. **非 HTTPS 上下文纯 JS FIPS 180-4 SHA-256 兜底**：因 `http://` 页面 `crypto.subtle === undefined`，在双端油猴脚本内置纯 JS `pureJsSha256Hex`，实测在真站非安全上下文精确算出 `202601` 字典哈希 `ab8e97496fbc9500877f02adc61ab214788f79234b9cb1f565a98f79234b9cb1f565a98f77a683a59b`（由 `customs-suite-v4.test.ts` 第 5 项测试固化）。
  3. **`browser-harness` 守护进程 64 KiB IPC 行长上限分块注入**：`browser_harness` 守护进程 `asyncio.StreamReader.readline()` 默认单行上限 64 KiB，直接注入 58 KB 含中文脚本经双层 JSON 转义后会超限；在 `agent_helpers.py` 改为 `4,000` 字符切片 + `ensure_ascii=False` 逐块拼接执行，单帧 `< 30 KB`（由 `test_chunked_bridge_injection_stays_under_64kib_ipc_limit` 固化）。
  4. **瑞数反调试 `debugger;` 零阻塞处理**：调用 `cdp("Debugger.disable")` 使页面混淆脚本中的定时 `debugger;` 语句完全变为空操作，消除 `Runtime.evaluate` 挂起超时。
  5. **真站时间锚点、`selectTableState` 三分支与 `/queryData/toCaptchaView` 会话验证码门禁合规熔断**：
     - 实测真站 `/queryData/queryDataByWhere` 同源内嵌框架当前锚点为 `#currentStartTime = "202504"`、`#currentEndTime = "202610"`；
     - 提取真站官方三分支规则：`selectStartTime >= currentStartTime && currentEndTime >= selectEndTime -> 1`（活跃 18 个月库：`2025-04..2026-10`），`currentStartTime > selectEndTime -> 2`（历史库：`<= 2025-03`，覆盖 `2022–2024` 全年及 `2025-01..03`），跨界窗口 `-> 3`；
     - 真站会话未在前端弹窗 `/queryData/toCaptchaView` 完成人工图形验证码解锁前，`/queryData/getQueryDataListByWhere` 与 `/queryData/downloadQueryData` 返回 `HTTP 200` + `0 字节`。双端脚本与 `collect_customs_5y.py` 严格遵守合规准则（绝不自动识别、点击、绕过或轮询等待验证码），立即识别 `captcha_session_gate_required`（`circuitBreakRequired: true`），原子落盘 `data/customs-raw/_checkpoint.json` 并安全退出提示人工完成一次验证后续采（由 `customs-suite-v4.test.ts` 第 6 项测试及真站实跑验证）。
